🗣 Sprachausgabe

Zack und alle Figuren sprechen ihre Texte mit echter Stimme (ElevenLabs).

Kostenlos registrieren auf elevenlabs.io. Der Schlüssel bleibt nur in diesem Browser (localStorage), nichts wird anderweitig versendet. Jede Zeile wird nur einmal generiert und dann wiederverwendet – trotzdem gilt: Sprachausgabe verbraucht Kontingent des eigenen ElevenLabs-Kontos.

So wird gespielt

Verb anklicken, dann ein Objekt in der Szene oder im Inventar – z. B. „Benutze“ → „Stock“ → „Elsternnest“.

Rechtsklick auf ein Objekt schaut es direkt an.

Leertaste / Klick überspringt Sprechtexte.

Nicht weiter? Taste T oder der Knopf „Tipp“ öffnet Zacks Notizbuch: Es sagt dir, was als Nächstes dran ist, auf Wunsch Schritt für Schritt deutlicher.

Tasten: 1–9 wählen das Verb (im Gespräch: die Antwort), H gedrückt halten zeigt alle anklickbaren Dinge, P = Foto-Modus (blendet alles Überlagerte aus), Esc schließt Fenster.

Touch: Antippen = Aktion, lange drücken = Anschauen. Unten links gibt es Schnellknöpfe: 👁 schaltet den Anschauen-Modus ein (dann wirkt einfaches Antippen wie langes Drücken), ◎ zeigt alle anklickbaren Dinge. Mit ☰ (oben rechts) erreichst du das Menü.

🗣 Sprache: Im Menü unter „Sprache“ kannst du ElevenLabs-Sprachausgabe aktivieren – dann lesen echte Stimmen alle Dialoge vor. Läuft komplett im Browser, Schlüssel wird nur lokal gespeichert.

Vollbild startet beim ersten Klick von selbst (Taste F, Knopf „Vollbild“ oder Esc beendet es). Auf dem iPhone: Teilen → „Zum Home-Bildschirm“.

Mit Figuren reden lohnt sich: Sie verraten oft, wie es weitergeht.

Das Spiel speichert beim Raumwechsel automatisch („Weiterspielen“ im Titelbild).
